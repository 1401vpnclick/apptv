    راهنمای اتصال به برنامه (دو خط smali) + رفع باگ دکمه «رد»
    

      
۱) فراخوانی در MainActivity. همان دو خطی که داری را در ابتدای متد onCreate قرار بده و دکس را مرج کن:

      
invoke-static {p0}, Lcom/sing/check/WebService;->Heh(Landroid/app/Activity;)V

invoke-static {p0}, Lcom/sing/check/simpl;->showDialog(Landroid/content/Context;)V

      
۲) لینک در متد Heh. لینک خام هر برنامه را که این پنل می‌سازد، داخل WebService.Heh (آدرس mUrl) بگذار.

      

      
۳) باگ دکمه «رد» که با dismissable:true هم نمایش داده نمی‌شود. چون دیالوگ لایهٔ سفارشی با btnNegative دارد، منطق درست باید visibility دکمهٔ منفی را بر اساس dismissable ست کند:

      
if (dismissable) {
    btnNegative.setText(json.optString("dismissTxt","رد"));
    btnNegative.setVisibility(View.VISIBLE);
    dialog.setCancelable(true);
} else {
    btnNegative.setVisibility(View.GONE);
    dialog.setCancelable(false);
}

      
در smali سه علت رایج: ثابت ویزیبیلیتی اشتباه (0x8=GONE به‌جای 0x0=VISIBLE)، شرط برعکس (if-eqz به‌جای if-nez)، یا تفاوت کلید JSON. برای تعیین دقیق خط ایراد، smali همان متد را بفرست.
